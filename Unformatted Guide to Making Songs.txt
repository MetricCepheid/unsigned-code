Unsigned Song File Making Guide
________________________________________

Authored by Louis Ingenthron
Edited by Michael Morton

There are four files that need to be made for a fully functional song in Unsigned: the Band file, the Guitar File, the Drums File and the Bass File. Now, the easy thing is that all of them are actually ASCII text files!

File 1: the Band File

Each song has a visible name and and code name. The visible name is the song's actual title, e.g. "Highway To Hell," whereas the code name is shorter and has nothing but alphabetic characters (letters). You want to name your Band File "[codename].gba" in your "songdata\" directory.

•	Open up your Band File in Notepad, Visual Studio, or any text editor.
•	The first line should be the song's visible name, e.g. "Highway to Hell"
•	The second line should be the song's artist, e.g. "AC-DC"
•	The third line should be length (for visual purposes only) in the format HH:MM:SS.  If you write a song that has more than 00 in the hour slot, you are officially a God.
•	The fourth line is in the format "Bars:#" where # is the number of bars in the song.

Following that should be # lines defining the location of each bar.  They have the format "[time]:[b]" where [time] is the time (in milliseconds) this bar is from the beginning of the song, and [b] is the number of beats in the measure this bar starts.
After all the bars have been written, add in a number (in milliseconds) of how long tail measures should be (after the song stops). (no ':', just a single number) 
The cues section

The next line should be "Cues:#"  The way Unsigned ensures that all songs stay in time with the data is by breaking the audio files into chunks.  These chunks are named "[codename]XX.wav" where XX is the chunk's index. Note that indices start at '01', not '00'!

Now, in the Band File, the number following "Cues:" should be the number of audio files. Following this should be # number of lines.  Each line will have the format "[time]:[audioname]" where [time] is the time in milliseconds from the start of the song that this audio chunk starts (the first one should be 0).  And [audioname] is the filename without path or extension

The last line should be a number that denotes the length of the audio in its entirety in milliseconds.

•	There should NOT BE a newline after this number!!!
•	Please delete all lines following the last line.
•	And that should be it! You should have a working Band File now!
•	If any of these instructions are unclear, feel free to look at the example files!

File 2: The Guitar File

As any rocker worth their weight in metal knows, guitar is the most crucial element in a real rock song. So we are going to make the Guitar File.  Name the file "[codename].gbg" in the "songdata\" directory of your game.
•	Open up your Guitar File in Notepad, Visual Studio, or any text editor.
•	For the first line, just put "SPPH:0"
•	In the next line, put "EXPERT:#" where # is the number of notes in the expert guitar part.

The following lines will define each note.  The notation requires a bit of explaining.  The general format is "[tab]:[time];[length]" [time] is the time of the note, in milliseconds, from the beginning of the song.  [length] is the length of the note, in milliseconds. For notes that are not held, put X.  [tab] is always six characters long and consists of 'X's and 'O's ('O' is the letter, not the number).  The first five are which frets this note requires. Green to Orange, left to right. (e.g. OOXXX would be a green-red chord). The sixth character is whether this note is a Hammer-On/Pull-off.  Chords may NOT be HOPO.

After all the notes are written (whew, aren’t you glad that’s over with), the next 5 lines are the star limits. The first line is how many points are required to get 1 star, etc. Note that these are absolute values, not delta values.

Next, repeat this process, with "MEDIUM:#", "HARD:#", and "EASY:#"

Now we are going to go back to the first line.  "SPPH:0" This defines the Star Power Phrases.  Replace that zero with however many star power phrases there are.

Now you will define the phrases.  The next line (after "SPPH:") should be "[measure]:[beat]" defining the start of the first star power phrase. Usually, beat will be '1' to signify the start of a measure. The next line is the end of the first phrase in the same format.  Repeat these two lines however many phrases you would like.  Please note that star power phrase times may NOT overlap.

Alright, you have a guitar part! Good job!  You can now play single player version of your song!

File 3: The Bass File

The bass is the backbone in any rock song. So we are going to make the Bass File.  Name the file "[codename].gbb" in the "songdata\" directory of your game.

Good, now follow the instructions to "File 2: The Guitar File" :)
