Unsigned 2.0 Change Log

=========Settings========================================================

The first time the game is started, it will detect many things about the system, including default language.

Option to view FPS has been deprecated.

Option to set "graphics level" has been deprecated.

Fixed Particles

=========InGameFeatures==================================================

Solos implemented!

Band Multipliers (when multiple band members use Rock Power)

Big Rock Endings!

=========Idols===========================================================

Idols on stage!

Idols have customizeable appearances

Idol animations on-stage react to players input

=========Look&Feel=======================================================

Rock Power has changed to a light blue color throughout the game.

The "Unsigned Orange" has been used throughout the game and menus to tie together the overall look.

Additional stars are shown on the side of the Unsigned-Style HUD to show how many stars have been achieved on a certain song.

Results Screen now shows the percentage of notes hit, the number of RP phrases hit, and the player's streak.

VenueCompiler now allows models, such as those pretty palm trees

Fans!

Animated Amps bump with bass drum and bass guitar notes

=========SongData Converter==============================================

Allows users to convert chart files to Unsigned Songdata files

Allows users to update old songdata files to new songdata files

Create lighting schemes, camera switches, solos, and Big Rock Endings to make your song more immersive
