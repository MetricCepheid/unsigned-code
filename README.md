# Unsigned
Unsigned is a Rock Band clone that was uploaded to a Sourceforge SVN repository on **Janurary 31st, 2008**.

Unsigned requires **Microsoft XNA Game Studio 3.0**, **Microsoft .NET Framework 2.0**, and **Microsoft Visual Studio 2008** to compile

Unsigned requires **Microsoft XNA Framework Redistributable 3.0**, and **Microsoft .NET Framework 2.0** to play.
